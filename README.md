# 在庫管理台帳 (Supabase版)

このアプリは Claude のチャット内プレビュー(アーティファクト)では動きません。
アーティファクトは外部ネットワーク(Supabaseなど)に接続できないサンドボックス環境のためです。
このフォルダは、あなた自身でホスティングして使う**独立したWebアプリ**として作られています。

実現していること:
- 複数人でのデータ共有(全員が同じSupabaseデータベースを見る)
- Aさんの登録がBさんにもリアルタイムで反映される(Supabase Realtime)
- 別のPC・スマホから開いても同じデータが使える(データはクラウド上のSupabaseに保存)
- メールアドレス+パスワードによるユーザーごとのログイン
- Postgresデータベースなので、複数人が同時に使ってもデータが壊れない
- 全データをJSONファイルとしてバックアップ書き出し・復元が可能

---

## 1. Supabaseプロジェクトを作る

1. https://supabase.com にアクセスし、無料アカウントを作成
2. 「New Project」でプロジェクトを作成(リージョンは Northeast Asia (Tokyo) がおすすめ)
3. プロジェクト作成後、左メニューの **SQL Editor** を開く
4. このフォルダ内の `supabase/schema.sql` の中身を全てコピーして貼り付け、実行(Run)する
   - これでテーブル(products, movements)・アクセス権限(RLS)・リアルタイム配信が設定されます
5. 左メニューの **Authentication > Providers** で「Email」が有効になっていることを確認
   - 社内ツールとして手軽に使いたい場合は **Authentication > Settings** で
     「Confirm email」をオフにすると、確認メールなしですぐログインできるようになります
6. 左メニューの **Settings > API** を開き、以下をメモしておく
   - `Project URL`
   - `anon public` キー

## 2. このプロジェクトをセットアップする

Node.js (18以上推奨) がインストールされたPCで、このフォルダを開いて:

```bash
npm install
cp .env.example .env
```

`.env` ファイルをテキストエディタで開き、先ほどメモした値を入力:

```
VITE_SUPABASE_URL=https://xxxxxxxxxxxx.supabase.co
VITE_SUPABASE_ANON_KEY=ここにanon publicキーを貼り付け
```

## 3. 動作確認(ローカル)

```bash
npm run dev
```

表示されたURL(例: http://localhost:5173 )をブラウザで開き、
「アカウントを新規作成」からメールアドレスとパスワードでアカウントを作ります。
同じ手順を別のメンバーのメールアドレスで行えば、全員が同じデータを共有できます。

## 4. 公開する(社内メンバーがどこからでも使えるようにする)

無料で使えるホスティングサービス(例: Vercel, Netlify)にデプロイするのがおすすめです。

**Vercelの場合:**
1. このフォルダをGitHubリポジトリにpush
2. https://vercel.com でそのリポジトリをインポート
3. 環境変数 `VITE_SUPABASE_URL` と `VITE_SUPABASE_ANON_KEY` をVercelのプロジェクト設定に追加
4. デプロイすると、発行されたURLに誰でも(ログインが必要)アクセスできるようになります

**Netlifyの場合も同様に**、ビルドコマンド `npm run build`、公開ディレクトリ `dist` を指定し、
同じ環境変数を設定してデプロイします。

デプロイ後のURLをスマホのホーム画面に追加すれば、アプリのように使えます。

## 5. データ構成

- `products` テーブル: 商品(旧: 品番)、色(旧: 商品名)、保管場所、メモ
- `movements` テーブル: 入荷・消費の記録(商品ID、種別、キロ数、記録者、日時)

現在の全ユーザーがログインしていれば読み書きできる設定になっています(社内共有ツール向け)。
もし特定の人だけ書き込みを制限したい場合は、`supabase/schema.sql` のRLSポリシー部分を
調整してください(例: 特定のメールドメインのみ許可、閲覧のみ許可するロールを作るなど)。

## 6. バックアップ

アプリ内の「商品登録」タブ下部にある「バックアップ」セクションから:
- **エクスポート**: 現在の全データをJSONファイルとしてダウンロード
- **復元**: エクスポートしたJSONファイルを選択すると、同じ内容をデータベースに書き戻します
  (IDが一致するデータは上書き、新しいデータはそのまま追加されます)

定期的にバックアップを取っておくことをおすすめします。
